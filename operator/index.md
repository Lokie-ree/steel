# Operator

The one thing that stays constant across every project: the person running them. Projects open and close under [[../projects/index]]. This folder holds the operator-level documents that outlast all of them. Opened 2026-09-22, when the vault began moving from ISTE-era hub to a project-to-project switchboard ([[../initiatives/public-identity]] §Next instances).

**These are first-person, operator-authored documents.** Agents read them for context and don't rewrite their voice.

| Doc | Purpose |
|-----|---------|
| [[ai-collaboration-context]] | Role, students, constraints, goals, and oath clauses. Paste it at the start of an AI session. Cited by filename in D-2026-08-23's `Why` cell. A bare filename is location-independent, so the move from the vault root broke nothing |
| [[build-inventory]] | One row per artifact that exists, `[verified]` / `[unverified]`: the count behind "what has actually been built." Only the operator flips a row to verified |

**Not here, on purpose:** [[../wiki/lessons]] and [[../wiki/journey]] are also about the operator, but they're harvested and distilled at project close. They stay in `wiki/` beside [[../wiki/patterns]], which the harvest writes to in the same pass.
